# ChatGPT 论文写作提示词

专用会话的日常任务只说改动位置、希望读者看懂的问题和所需产物。新会话补论文名和已指定基稿。真实项目以当前连接返回的 project_id 为准，授权范围沿用当前用户请求。下列示例按实际任务选用。

## 局部修订与继续

> 接续 <论文名或当前已核稿件>。只改 <具体段落或图注>，让读者看懂 <设计理由、对照或结果>。给实际改好的正文与修改位置，按本轮要求交付中文对照或审阅件。

收到“继续”时，沿同一稿件和已接受的意见恢复最近未完成的授权步骤。

## 图件反馈

> 改 <图号及面板>。从当前 TeX 和已核图源确认它回答的问题，采用 <参考的关键特点>，解决 <实际阅读障碍>。给实际页面尺度的预览和可继续编辑的源。

## Prompt A：REVISION

> 使用 web论文写作，连接 <项目名>。以 <已核验基稿> 为底稿，完成 <章节或整稿> 的修订。核对当前稿件、原批注、证据与作者已确认选择。对于需要重构的段落或图，先给有证据的成稿样例，再在本轮获准范围内写完。交付 <所需语言、范围和审阅件>，给出实改位置和检查结果。

## Prompt B：REBUILD

> 使用 web论文写作，连接 <项目名>，在 <科学问题> 下从 PaperWriting 的已核材料重新设计和撰写全文。先用证据与代表性正文明确主线、图表顺序和待决定事项，再写完整候选。交付 <实际正文、配套图表及本轮授权的构建或审阅件>。

REVISION 与 REBUILD 的完整任务按[全文工作流](full-workflow.md)使用现有 WRITING_BRIEF.md 和专业技能。只有会实质改变贡献、方法、数据含义、论文身份或授权范围的抉择才需要新的作者决定。工具返回、已构建、实际目视和作者接受均按实际证据记录。纯取件按[精确目标取件](indexed-targets.md)办理。


全文可按需用 Nature Writing 和 Nature Figure。按本轮真实授权与回执提供 Drive 审阅链接。不要把计划写成结果，不要修改冻结数据。

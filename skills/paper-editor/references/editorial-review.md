# 论文表达与编辑验收

局部写作只读与目标相关的部分。已有项目体例、作者已确认的表达和目标刊要求优先。参考论文用于比较具体的行文或图表选择，科学结论来自本项目证据。

## 正文

全文围绕读者能复述的中心回答组织。每个段落做好一个主要任务。首句让读者知道它正在回答的问题，随后给出紧邻的对照、证据或解释，下一段接着解决尚未回答的问题。句数随论证需要。用有明确对象的主语和动词，保持术语、公式与图表含义一致。直接写观察结果，关键条件、统计单位、反向结果和不确定性放在会影响解读的位置。英文按实际目标稿自然成文，中文供对照与审查，两者共享方法、数值、单位、分母和结论强度。反防御写作按[随包原文](anti-defensive-writing.md)执行。

| 部分 | 读者应得到的内容 |
| --- | --- |
| 标题与摘要 | 任务和关键困难、处理机制、决定性比较、证据覆盖范围。主要数值带对象和条件。 |
| 引言 | 具体科学问题、最接近研究所处的观测或假设、尚待解决的缺口、本文如何检验它。 |
| 相关工作 | 依任务或机制对比最相关方法，说明本稿实质差异。用实际阅读的版本及位置检查引用句。 |
| 方法 | 输入、输出、操作及接口，关键设计为何必要，训练与推断可见的信息。公式、图和实现能交叉核对。 |
| 实验与结果 | 独立单位、比较条件、分母和干预。按问题给出答案与关键对照，写清哪个配置重训或固定、分别能推出什么。 |
| 讨论与结论 | 结果怎样改变机制或适用条件的判断，保留实质反例与限制。结论回答开头的问题。 |
| 图注、表题、补充材料 | 交代面板、实际比较量、单位和统计口径。补充材料承载完整结果、诊断和复现细节，正文保留决定结论的证据。 |

完整起稿宜先梳理核心证据、方法与 Results，随后让引言指向已能支撑的结果。成熟稿按用户指定范围修订。需要参考外部范例时，记录实际看过的段或图、可迁移的写法和本稿应用位置，一个适切例子即可启动具体改进。

## 图表

先从当前 TeX 和真实图表定位科学问题、面板、数据和统计单位，再决定样式。方法图按输入到输出核节点、边和方向。实测结果可按问题选择表格、配对差值图、曲线或分布图。选择误差与成功率曲线时明确有限返回与全部合格样本的分母。有序坐标和区间来自真实记录。颜色与标记角色在本文中一致，留白支持分组。

在实际嵌入尺寸看已渲染图，核对箭头落点、重要标签、文字裁切、图例、比例和正文引用。仅验对象可编辑或已导出时如实记录。依据选定参考核对作者指出的比例、信息层级、照片或其它需要保留的项目选择。编辑源、数据、导出和实际稿件位置用现有图件索引接续。

## 改后检查和作者意见

局部任务先在当前稿源逐项定位指定的原段落、图注或图件，并记录语言和位置。准备写作输入时，把这些可替换原文与仅供阅读的上下文、补充证据区分开。每个指定位置给一份对应替换；需要改相邻内容时，可单独提出依据。写回前按当前源核对实际差异仅落在指定位置，源已变化时重新定位。在实际候选上比较基稿和改后内容，复核本轮主要阅读问题。完整任务先用具备实际证据的一段正文或一组关键图检验表达方向，再推进同一范围内的成文。作者已明确允许的工作直接继续。

对实质改动记录原作者意见、对应位置、本次差异和复核结果。保存已经接受的具体表达和图件取舍。已有 Writing Brief、批注表或候选记录时沿用该入口；无须为一次微调创建第二份状态库。作者接受、读者能复述、工程构建和实际目视有各自证据。可请独立读者复述稿件的问题、对照和结论，仅给实际候选与必要证据。开启新的试写对比时记录同一基稿、证据、任务与可见模型设置。

稿件交付按[验收项](quality-gates.md)执行。

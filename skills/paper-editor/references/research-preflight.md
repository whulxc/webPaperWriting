# RESEARCH_PREFLIGHT 文献预研规范

本阶段只在 REVISION 的全文重构或 REBUILD 中默认执行。局部段落润色、单图修订和已完成的参考论文分析可以复用已有记录，不重复检索。

## 目标

在正式设计论文故事和写作前，建立一份可核验的文献预研记录，连接：

- 当前项目的科学问题和研究缺口
- Zotero 中已有条目、集合和稳定引用键
- 公开学术来源的真实元数据
- 约三篇用于写作和图件分析的代表性论文
- Introduction、Related Work、Discussion 所需的科学论证引用

三篇是深度结构学习的默认数量，不是科学文献检索总量上限。更多文献按项目的论证需求、证据范围和检索预算选择。

## 三类参考论文

### Scientific Story Reference

用于观察科学问题提出、研究缺口、贡献边界、Introduction 组织和整篇论文的叙事节奏。

至少记录：

- DOI、题名、作者、期刊、年份
- 实际阅读范围
- Introduction 的问题、缺口和贡献结构
- 可迁移的叙事原则
- 不适用于当前项目的做法

### Experimental Narrative Reference

用于观察 Results 的顺序、比较实验、消融、泛化、误差分析和结论如何回到证据。

至少记录：

- 实际阅读的 Results、Methods 或图注范围
- 实验问题到结果的安排
- 比较对象、统计单位和条件说明
- 可迁移的结果组织原则
- 当前项目缺失或不可比的条件

### Scientific Figure Reference

用于观察 Figure 1、方法图、实验图、多子图布局、颜色编码、视觉层次和图注设计。

至少记录：

- 实际查看的 Figure 编号、图注和页面
- 图件证明的科学结论
- 子图顺序、比较关系和颜色语义
- 可迁移的设计原则
- 不应复刻的原图元素和版权边界

## 证据等级

每篇论文分别标记：

- metadata_only：只核对元数据，不能声称读过全文
- abstract_only：读到摘要，不能声称分析正文段落或图件
- full_text_partial：只读了指定章节、页码或图注
- full_text_reviewed：读取并记录了完整论文的范围
- figure_reviewed：实际查看了指定图件页面或图像

文本提取不等于视觉查看。只有实际看到图件页面或图像时才能写 figure_reviewed。

## 操作顺序

1. 从项目现有引用索引、BibTeX 或已授权的 Zotero 集合中寻找候选。
2. 用实际可用的文献工具或出版商、DOI 注册机构等来源核对 DOI、题名、作者和出版信息。
3. 在合法可访问的情况下读取全文 PDF、HTML、图件和图注。
4. 将三篇论文按上述三种角色登记到 Writing Brief。
5. 记录实际阅读范围、来源链接或 Drive/File ID、页码和图号。
6. 将可迁移原则写入 Brief 并用于本轮叙事和图件设计，用户另装的写作或图件技能可按需辅助。保留原创表达和图件来源。
7. 把支持本项目 Introduction、Related Work、Discussion 的其他论文按普通文献证据登记。

## Zotero 边界

- 默认只读 Zotero 集合、条目、标签、附件路径和稳定引用键。
- 用户明确要求管理书库时，才调用 Zotero 写入入口。
- 不把参考论文结构笔记写进 Zotero 条目，写入当前项目的 Writing Brief 或项目审阅目录。
- 不将私人登录、访问令牌、Cookie 或完整全文载荷写入共享技能、项目 Git 或 Drive。

## 通过条件

RESEARCH_PREFLIGHT 通过需要：

- 至少三篇角色明确的参考论文，或记录无法满足数量的具体原因
- 每篇有真实元数据和实际阅读范围
- 论文结构观察与当前项目证据分开
- 需要支持的科学主张已有后续检索计划
- 未调用额外收费 API，或明确记录了用户已授权的服务和成本

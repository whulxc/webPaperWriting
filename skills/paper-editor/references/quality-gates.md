# 独立验收项

事实、工程、版式、表达四门分别核验。成熟具体流程继续见 [科学证据](scientific-evidence.md)、[任务模式](task-modes.md)、[版本交付](build-version-delivery.md)，不维护第二套科研政策。

事实：claim → 原始来源/selector/版本/SHA → 可复算数值或明确推断 → 稿件位置。分清 synthetic、真实结果、计划和未验证。统计独立单位、划分、分母、缺失值和不确定性不能因风格省略；负面/混合结果不能隐藏。书目身份与论断支持分开。

工程：原生 PPTX/SVG/TikZ 或可执行数据图源保持可编辑；若项目要求可编辑，不用整页 bitmap 伪装。节点/边须有方法来源，训练与推理边界清楚；默认 imagegen 建议不能覆盖项目原生图契约。源文件实际重新渲染，与交付预览对应，独立目录重建、hash/manifest 验证依任务要求执行。

版式：实际查看 PDF 页图和图件最终嵌入尺寸；核字号、裁切、箭头方向、层次、语义、比例、可读性及颜色/线型。OOXML 属性正确不等于渲染正确。重要方法图做独立盲读，记录实查页/区域；抽查不得称全页通过。

表达：按[论文表达与编辑验收](editorial-review.md)复核实际差异。读者能否复述本段问题、对照与结论，作者已批注的阅读障碍是否解决，跨轮已接受的内容是否保留。范围内检查与本次改动相称。作者接受有明确记录时才标记接受。

交付至少分列：源/版本身份、构建状态、事实/数值检查、视觉审阅、编辑性/可重建、云端上传及读回、ChatGPT 字节/预览接收、用户实际打开。N/A 与未验证分开。默认 Drive 交付使用 Runner 的构建、本机渲染与检查、原 Publisher 的服务端校验。Chat 的视觉审阅按已核 Drive PDF 或页预览 ID 读取；未要求ChatGPT完整字节校验时，该项记“未执行（本轮不要求）”，不是附件缺失导致验收失败。Publisher校验、ChatGPT元数据核验、已看页图、完整PDF取得与独立SHA重算分别记实；后两项不能从前面推断。完整文件路径依[附件例外](build-version-delivery.md#默认drive交付与附件例外)。

不可变 bNNN / 发布快照保留源码、依赖、图源、PDF、日志、页图、hash、rb 任务映射。工作版本不随每次构建增加。失败日志和回执保留，恢复新任务必须明确原 failed ID 与审计关联。

技能目录存在、静态触发测试、local mock、真实服务调用、新 Chat 自主选择工具是不同证据。交接列实测范围与限制，不把 Codex 自测写为 ChatGPT 独立验收成功。

结构核验按 [工程结构](workspace-layout.md) 检查职责、四类索引角色/字段/覆盖范围、逻辑路径与当前输入身份。AGENTS中的稳定规则不得与STATE的当前状态混写；检查通过不要求历史目录重排或证据表全量重算。

Codex阶段还须通过 [完成情况交付](codex-delivery.md)：写作根与材料内容简介、文献数量/位置、实际连接、Drive语义名称/路径、Chat要求和推荐提示词全部有实据或明确缺口。空目录、通用骨架、索引数量和本地healthz均不能单独使该项通过。新根注册不代表旧构建配方已绑定新稿，必须独立核输入SHA、引擎与输出位置。
